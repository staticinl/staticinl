### 🔭 What I do

I'm a graphics programmer focused on **real-time rendering** — the systems that let games and engines draw a frame, fast, every frame. I work primarily in **C++**, comfortable building projects end-to-end and wiring up the build systems that hold them together.

### 🎮 Featured project — Impaction

**[Impaction](https://github.com/staticinl/Impaction)** is a cross-platform game engine I'm building from the ground up, written in C++ with OpenGL as the rendering backend.

- 🖥️ Targets **Windows** and **Linux**
- 🎨 Rendering backend: **OpenGL**
- 🧩 Built to be cross-platform from day one, not bolted on later

I'm actively learning game engine architecture and graphics programming *through* building Impaction — so the repo doubles as a running log of that process.

> 👯 **Looking for contributors.** If engine dev, rendering, or graphics programming interests you, I'd love company on this — check the repo and open an issue or PR.
